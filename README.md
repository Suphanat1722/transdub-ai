# TransDub AI

TransDub AI เป็นเว็บแอปบน Windows สําหรับพากย์วิดีโอ YouTube เป็นภาษาไทยตั้งแต่ต้นจนจบในงานเดียว:

1. กรอกลิงก์ YouTube → ระบบดาวน์โหลดวิดีโอ (yt-dlp) และดึงคำบรรยายจาก YouTube
2. ซับไทย → ใช้เป็นข้อความพากย์ได้เลย / ซับภาษาอื่น → Gemini แปลเป็นไทยก่อน
3. แยกเสียงพูดออกจากเพลง/บรรยากาศด้วย Demucs (หรือข้ามได้ด้วยโหมดเร็ว)
4. สร้างเสียงพากย์ด้วย Microsoft Edge TTS (เสียงสำเร็จรูป เลือกได้หลายเสียง)
5. ประกอบเสียงพากย์แบบไม่ทับกัน ผสมกับ background stem แล้วประกอบกลับเป็น MP4

แอป bind เฉพาะ `127.0.0.1`, เก็บงานใน SQLite และ checkpoint รายขั้น/ราย chunk เพื่อทําต่อหลังปิดโปรแกรมได้ มีเพียงข้อความที่ต้องแปลเท่านั้นที่ส่งไป Gemini; การดาวน์โหลดวิดีโอ/ดึงซับ (YouTube), Edge TTS, Demucs และการประกอบวิดีโอทําผ่านบริการ/บนเครื่อง

> **เสียงและสถาปัตยกรรม**: ระบบเป็นแบบ YouTube-only — รับลิงก์วิดีโอ YouTube แล้วดึง subtitle ที่มีอยู่บนYouTube (ภาษาไทย/อังกฤษ/อื่น ๆ) มาใช้เป็นต้นฉบับ ไฟล์วิดีโอที่ไม่มีซับบน YouTube จะใช้ไม่ได้
> ซับภาษาไทยไม่ต้องผ่าน Gemini เลย (ใช้เป็นเสียงพากย์ตรง ๆ) ซับภาษาอื่นส่ง Gemini แปลเป็นไทยก่อน
> เสียงพากย์ใช้ **Microsoft Edge TTS** (preset voices, ไม่มี voice cloning) ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อเข้าถึงบริการและสำหรับ YouTube
>
> **ถ้า YouTube บล็อก IP (เจอ "ถูกบล็อก/TooManyRequests")**: ตั้ง proxy ใน `.env` ได้ (`YOUTUBE_PROXY_WEBSHARE_USER`/`PASS` หรือ `YOUTUBE_PROXY_URL`) — ถ้าใช้ Webshare ต้องซื้อแพ็กเกจ **Residential** เท่านั้น ดูรายละเอียดใน `.env.example`

## เริ่มใช้งาน

ต้องมี Windows, Python 3.12, Git, FFmpeg/FFprobe และอินเทอร์เน็ต

1. รัน `Setup.ps1` หรือดับเบิลคลิก `Start TransDub AI.bat` เพื่อให้ติดตั้งอัตโนมัติ
2. ใส่ `GEMINI_API_KEY` ใน `.env`
3. ดับเบิลคลิก `Start TransDub AI.bat`
4. เปิด <http://127.0.0.1:8765>

สร้างงานด้วย wizard 3 ขั้น (วิดีโอ → เสียง → เริ่ม) ค่าเริ่มต้นวิ่งอัตโนมัติจนจบไม่พักรอตรวจ อยากตรวจก่อนแปล/ก่อนสร้างเสียงค่อยเปิดใน “ตั้งค่าขั้นสูง”

## การทํางานและไฟล์

- กรอกลิงก์ YouTube แล้วระบบดาวน์โหลดวิดีโอและดึงคำบรรยายให้ ถ้าซับเป็นไทยจะไปสร้างเสียงพากย์ได้ทันที ถ้าเป็นภาษาอื่นจะแปลด้วย Gemini ก่อน (ค่าเริ่มต้นไม่พักรอตรวจ)
- หน้าเว็บให้เลือกรายการเสียง Edge TTS และอัตราการพูด (rate) ได้ รายการเสียงจัดกลุ่ม "เสียงไทย" ขึ้นก่อนพร้อมช่องค้นหา (กด "แสดงเสียงภาษาอื่น" เพื่อดูทุกเสียง)
- **เสียงไม่ทับกัน ไม่ตัดคําทิ้ง**: cue ที่เสียงพันกันถูกจัดเป็นกลุ่ม วางต่อกันแบบไม่มีทับ แล้วเร่งทั้งก้อนด้วยจังหวะเดียว (สูงสุด 1.5x) ให้พอดีช่วงซับ — cue เดี่ยวที่ไม่พันใครคงจังหวะธรรมชาติ ถ้าเร่งสุดแล้วยังล้นจะหยุดที่ `needs_review` ให้ตรวจ/ย่อข้อความแทนการตัดคําพูดทิ้ง
- งานที่เสร็จแล้วกด **ประกอบเสียงใหม่** ได้ (ประกอบใหม่ด้วยตรรกะล่าสุดโดยไม่สังเคราะห์เสียงซ้ำ) หรือ **มิกซ์ MP4 ใหม่** เมื่อปรับระดับเสียง
- แก้ตั้งค่างานที่สร้างแล้วได้จากการ์ด "ตั้งค่างาน": เสียง, อัตราการพูด, ระดับเสียงพื้นหลัง/พากย์ และโฟลเดอร์ส่งออก — เปลี่ยนเสียงหรืออัตราการพูดจะลบเสียงที่สร้างไว้แล้วสร้างใหม่ทั้งหมดโดยข้อความ/คําแปลคงเดิม
- หน้าตรวจ cue มีช่องค้นหา, กรอกเวลาได้ทั้ง ms และ `HH:MM:SS,mmm`, ตรวจเวลาทับกันแบบ live, บันทึกทีละหลาย cue ได้, ฟังเสียงพูดเดี่ยว (▶) หรือเสียงพูดผสมเสียงพื้นหลังช่วงนั้น (🎚) เพื่อตรวจก่อนยืนยันคําแปล
- แก้ข้อความ/timecode ในหน้าเว็บได้ — แก้ฝั่งคำแปลล้างแค่เสียงที่เกี่ยวข้อง ส่วนแก้ต้นฉบับแบบข้อความอย่างเดียวระบบจะแปลใหม่เฉพาะช่วงที่กระทบ (ประหยัด Gemini) ถ้าแก้เวลาจะล้างทั้งงาน (ระบบจะถามยืนยันก่อน)
- เลือกโฟลเดอร์ส่งออกวิดีโอเสร็จได้ (มีปุ่มตรวจว่า path ใช้ได้) ถ้าไม่เลือก ระบบบันทึกไฟล์ `.th-dub.mp4` ไปที่โฟลเดอร์เดียวกับวิดีโอต้นฉบับ
- ติ๊ก “โหมดเร็ว: ข้าม Demucs” ตอนสร้างงานได้ถ้าเครื่องช้า (ใช้เสียงต้นฉบับเป็นพื้นหลังแทน ไม่ต้องมี torch/CUDA)
- เปิดการ์ด “บันทึกงาน” ในหน้างานเพื่อดู error/warnings + ประวัติ stage ล่าสุดก่อนกด retry (`GET /api/jobs/{id}/logs`) งานที่รอคิวเห็นเลขคิวด้วย
- หาก Gemini รวม cue สั้นหรือส่ง timecode เหลื่อม ระบบจะแบ่ง chunk แล้วลองใหม่อัตโนมัติ พร้อมบันทึกคําเตือนการจับคู่ไว้ให้ตรวจ
- คิวงานรันทีละ 1 งาน งานที่เหลือรอคิวอัตโนมัติ ปิดโปรแกรมแล้วเปิดใหม่ระบบกู้งานค้างให้เอง
- เก็บ source/translated SRT, background FLAC, dub WAV/MP3, report และ final MP4
- ไฟล์ชั่วคราวอยู่ใน `data/jobs/<UUID>/work` และถูกลบหลังงานสําเร็จ

## มีอะไรใหม่ใน 1.4.0

- Wizard สร้างงาน 3 ขั้น + ค่าเริ่มต้นวิ่ง auto จนจบ
- ประกอบเสียงแบบกลุ่ม (overlap groups) จังหวะเดียวทั้งก้อน + ปุ่มประกอบเสียงใหม่
- โหมดเร็วข้าม Demucs, การ์ดบันทึกงาน, เลขคิว, ตัวกรอง/ค้นหางาน + ลบงานที่จบแล้วทีละชุด
- แก้ต้นฉบับแบบข้อความอย่างเดียวแปลใหม่เฉพาะ chunk ที่กระทบ
- ทน YouTube bot-check ด้วย Chrome TLS fingerprint + fallback หลาย player client
